Juris-IA Maroc

PFA · 2026

Assistant qui répond à des questions sur le Code Pénal marocain, en arabe et en français, dans une interface de chat. Pour chaque question, la recherche combine deux méthodes : l'une trouve les mots exacts (un numéro d'article, par exemple), l'autre trouve le sens. Un reranker remet les passages dans le bon ordre avant que le modèle rédige sa réponse.
